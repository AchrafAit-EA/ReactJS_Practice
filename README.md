## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/AchrafAit-EA/ReactJS_Practice.git
   ```

2. Navigate to the project directory:

   ```bash
   cd test1
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
